# Changelog for `pykinos-penelope`

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to the [Haskell Package Versioning Policy (PVP)](https://pvp.haskell.org/).

## [0.1.0.2] - 2026-11-19

### Changed
- Bump package version to 0.1.0.2 to synchronize forge releases, CI, and Hackage upload artifacts.
- Dual-license package under EUPL-1.2 OR Apache-2.0.
- Elaborate documentation corpus to Cellarius standards.

## [0.1.0.0] - 2026-11-18

### Added
- Transient epoch mutation integration with Penelope effects (`withTransientEpoch`).
- Lockless MVCC pushout merge handles (`pushoutMergeMVCC`).
- High-performance blocked transaction isolation.
- Comprehensive Hackage package manifest, documentation, and unit test suite.
